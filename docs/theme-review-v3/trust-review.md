# 三主题独立评审：普通访客的信任与信息披露

推荐默认使用 **C**，置信度中等。C 对“这是什么、需要花多少、怎样开始”的解释最直接，适合手机首次访问；B 对主动查验开奖依据的访客更强。默认权重下两者仅差 0.10 分，这只是本次 AI 启发式判断的细小差异，不代表真实转化差距。

## 范围与口径

只阅读 `materials.md`，并用 `view_image` 逐一查看 A、B、C 的 desktop、mobile、overview 共九张截图；未读取旧报告、README、源代码、其他评审或网站。不推测旧默认主题。截图可见主题选择器，因此不称为严格盲评。

按普通首次访问者、手机优先兼顾桌面评分，每项 1–5 分，允许 0.5 分；预先采用吸引力 30%、彩票期待感 30%、信任感 40%。这是 AI 启发式评审，非真人样本、A/B 实验或统计显著性结论。

## 独立评分

| 主题 | 吸引力 | 彩票期待感 | 信任感 | 加权分 |
| --- | ---: | ---: | ---: | ---: |
| A | 4.0 | 3.5 | 3.5 | 3.65 |
| B | 3.5 | 4.0 | 4.5 | 4.05 |
| C | 4.5 | 4.0 | 4.0 | 4.15 |

**A**

- 吸引力 4.0：紫色球体、熟悉选号与 16 国探索有鲜明的浏览诱因，但第一次看到的人仍需理解“全球玩法”和股票行情之间的关系。
- 彩票期待感 3.5：共享池与停售进程提供具体等待对象，主标题和主按钮却主要引向玩法探索，对“这一期怎样参与并等待结果”的引导稍弱。
- 信任感 3.5：手机积分条、时间说明和下方“全球只指玩法灵感”的解释有帮助，但首页主路径偏探索，核验依据与边界不如 B 容易被主动阅读。

**B**

- 吸引力 3.5：“结果自己核对”容易理解且有辨识度，但主动作先要求看开奖依据，普通新访客的开始意愿可能弱于 C 的直接体验入口。
- 彩票期待感 4.0：问号球体、共享池和“先看清开奖，再试试手气”把未开奖状态与参与衔接起来，没有依赖夸大回报制造期待。
- 信任感 4.5：主按钮直达本期依据，下面三张卡依次解释规则锁定、来源核验、结果复算，使共同具备的核验能力在首页更容易被发现和理解。

**C**

- 吸引力 4.5：清爽的绿色、低门槛标题和免费积分体验按钮，再配一次赠分与每注成本的解释，让普通访客更容易判断是否愿意开始。
- 彩票期待感 4.0：标题把小额积分消耗与等待开奖联系起来，共享池和时间卡提供具体对象，期待感来自参与过程而非收益承诺。
- 信任感 4.0：积分性质、无充值提现及中奖可能低于票价的说明很实用，但“怎么核验、能核验到哪里”主要依赖次要入口和页尾说明。

上述 B 的信任优势来自信息层级与入口突出程度，绝非拥有独占的核验能力；三主题共享积分池、结果卡、国家入口、手机时间卡及可读核验页，按相同标准计入基础分。

## 共同信息的实际理解风险

- **共享池与头奖：**三主题都写了“当前共享奖池”“全部玩法共用”“虚拟积分”，已经提供澄清，但最醒目的 `101,000` 缺少紧贴数字的“分”单位，仍容易先被读作某个头奖或个人可得金额；“查看奖池流水”也不能直接回答某一奖档能得多少。
- **当前进度与历史结果：**结果卡确实展示等待，没有把 DEMO 号码当真实结果，手机也明确“最早核验不是保证开奖”；问题是“最近开奖结果”这个栏目名先暗示已有历史，而桌面首屏只有停售倒计时，普通人可能把停售和开奖当成同一个时刻。
- **“全球”与行情来源：**16 国格子和品牌附近的全球定位很显眼，A 在下方最明确解释它只是选号结构灵感；Yahoo Finance、Nasdaq 和三个股票代码虽出现在共同时间卡中，仍不能保证首次访客会自然理解为“固定美股篮子，而非全球股票数据或各国官方彩票”。
- **核验入口与边界：**三主题手机首屏都有规则与时间入口，是共同优点；不过页尾边界字小，公开输入和号码可以复算，不等于私有原始行情响应、完整账本或整个系统已获认证，B 的“自己核对”也需要就近限定范围。

## 权重敏感性与适用场景

以下权重按“吸引力 / 彩票期待感 / 信任感”排列，仅用于展示偏好变化，不是客观正确的权重。

| 预定默认 | 30 / 30 / 40 | 3.65 | 4.05 | 4.15 | C |
| 等权 | 各 1/3 | 3.67 | 4.00 | 4.17 | C |

| 偏信任 | 20 / 20 / 60 | 3.60 | 4.20 | 4.10 | B |

**C 适合作为普通新访客的默认。**B 可在关注股票生成号码、公平性或主动求证的访问场景胜出，偏信任权重也会直接改变推荐。A 可在访客明确想了解各国选号规则、比较范围和概率的入口场景胜出，但在本次“普通首次访问、手机优先”的综合任务中没有领先。截图无法证明真实用户会按上述方式行动，因此不把 0.10 分当作强结论。

## 三个优先优化

1. **在三主题共享池卡内直接消除金额误认。**标题改为“当前共享积分池”，数字显示“101,000 分”；数字下固定写“全部玩法共用；池余额不等于个人可得奖额；无现金价值”，并在“查看奖池流水”旁增加“查看奖档与结算规则”，让余额、奖档和个人奖励的区别在同一处可理解。

2. **让时间卡与结果卡共同讲清“现在还没有结果”。**桌面时间卡补齐手机已展示的停售、最早核验、时区和来源缺失或分歧就等待的说明；首期未出结果时将结果栏目标题显示为“首期尚未开奖”，保留“尚无可展示的真实开奖结果”，并链接到同一本期时间与规则；将来确有结果后再切换为带期号和实际公布时间的历史结果，避免历史结果与当前池余额被当作同一期奖励。

3. **在首屏增加一句数据范围说明，并让核验入口带上边界摘要。**在 16 国定位或主介绍附近固定写“16 国指选号结构灵感；本期号码使用预先固定的美股篮子生成”，将规则入口统一标成“查看规则、来源与核验范围”；入口附近用两行普通话说明“能核对：公布输入与号码计算；不能证明：私有原始行情响应与完整账本”，再补“仍依赖数据源、托管及管理员”，并保留进入可读核验页的链接，三主题一起应用。
