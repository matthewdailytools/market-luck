## 评价基线

对象是手机优先的普通首次访问者，同时参考桌面。三项各1–5分，允许0.5分；预先固定总权重为吸引力30%、期待感30%、信任感40%。重点看访客能否快速回答“这是什么、我能做什么、何时有结果、如何核对”。

统一事实：这是无现金价值的虚拟积分体验，注册一次赠1,000分，每注10分，无充值提现。101,000是三主题共享的积分池；16国是选号结构灵感，真实行情来自固定美股篮子。首期仍开放，尚无真实结果。11月2日16:30停售，11月4日05:00最早开始核验，均为北京时间；来源缺失或分歧就等待。这些共用能力不能计为某主题独占优势。

### A：探索理由明确，开始动作不够具体

- **吸引力4.0**：紫色球体与“从熟悉的一注，逛到世界的玩法”形成一致的探索主题；“不必一次学会”降低16种规则的认知负担。手机主按钮“探索16国玩法”和次按钮“从玩法规则开始”都像阅读入口，访客尚不能很快判断哪个会进入选号。相较C，免费积分与下一步动作没有成为标题的主线。
- **期待感3.5**：共享奖池与倒计时都清楚可见，国家网格也提供持续探索的理由。但首屏主要承诺“逛玩法”，没有把“选择规则—选号—等待核验”的个人参与过程连起来。“16”球体强化玩法数量，对本期进程的帮助有限。
- **信任感4.0**：手机积分说明、完整时间卡、等待规则与核验入口均在首屏可见；下方明确“全球”仅指玩法灵感，以及当前实际美股篮子。扣分来自范围说明在较后位置，首屏的“世界/16国”可能先形成更广的行情覆盖印象。核验能力与B/C相同，差别是解释的优先级。

### B：核验动机最强，开始体验要多做一次判断

- **吸引力3.5**：“好运值得期待，结果自己核对”直白且有可信的个性；但手机用户在理解玩法前先面对“看懂本期开奖依据”的主动作。时间卡已提供规则与时间入口，紧邻的黄色主按钮又指向核验；真正开始的“用积分试试手气”是次级按钮，增加首次访问者选择路径的负担。
- **期待感4.0**：球体问号与“先看清开奖，再试试手气”保留未知结果的悬念；“规则先锁定—行情核验—结果复算”的三张说明卡，使期待依附于具体程序。与其他主题相同，首期等待态没有伪装成已开奖，也没有把最早核验时间承诺为开奖时间。开始路径偏核验，限制参与感继续上升。
- **信任感4.5**：标题、主按钮和下方三张说明卡都围绕可检查事项展开，“缺失或分歧就等待，不临时换日”特别有助于理解规则。高分来自呈现与入口的显著性，不是核验能力更强。仍不评5分：公开可读页不认证私有原始行情响应和完整账本，且这些边界在截图中属于低显著度页尾文字。

### C：最适合默认起点，核验入口重复消耗首屏空间

- **吸引力4.5**：“花一点积分，留一份期待”与“免费体验积分玩法”建立清楚的体验利益；手机顶部积分条先给出预算和性质，桌面正文也解释赠分、票价与无充值提现。绿色、金色球体与主按钮有明确视觉焦点。相比A的探索和B的核验，普通访客更容易知道自己可以开始做什么。
- **期待感4.0**：每注10分使参与成本具体，奖池与时间卡让期待有目标、有过程；下方“命中奖档不等于回本”诚实限制收益想象，不因此扣分。尚欠半步是主按钮仍用宽泛的“体验”，不能直接预告接下来会选玩法或选号；本期仍无结果，现有“最近开奖结果”标题也没有帮助建立当前进度。
- **信任感4.0**：风险与积分性质最容易理解，核验入口在手机首屏可达。下方“注册成功一次赠分”“登录不重复领取”“无现金充值”等进一步减少误解。但对“为何可以自己核对”的解释没有B集中，手机时间卡与旁边次按钮同名，容易把核验看成重复的规则说明。原始响应与账本边界同样较隐蔽。

## 手机路径与桌面差异

三个手机截图都先展示品牌、语言、登录与主题选择器，再进入标题、积分条、奖池和较高的时间卡，最后才出现开始按钮。材料中的核验入口底边均为663px，在844px视口内可见；因此不能说A或C缺少首屏核验。共同问题是开始动作接近首屏下部，而顶部手机导航没有桌面的“选号大厅”。“你想先了解什么”的三个胶囊实际是主题选择，不应被当作开始玩法导航。

C的黄色主按钮文字最有开始意图，但时间卡“查看本期规则与时间”与它旁边的同名次按钮重复；B则把相邻两个醒目入口都用于核验。A两个首屏按钮分别到玩法和规则，区分有依据，但措辞都偏探索。截图不能证明锚点落位、登录门槛或国家选择后能否直接选号，相关交互需后续单独验证。

桌面三主题均能同时看见大标题、奖池、CTA和装饰球，较少受到手机纵向排序的限制。C正文补足积分条件；A/B没有同样显著的完整积分说明条，但共享奖池注释仍写明虚拟积分、无现金价值。下方结果卡均真实显示等待，国家网格和核验页是共享内容，不能反复归为某主题的特有优势。

## 三项最高优先的可实现优化

1. **把手机版开始路径前移，并弱化主题选择对首次任务的干扰。** 位置是当前首屏“你想先了解什么”胶囊区及hero内CTA行。将主题胶囊移到hero之后，或改为占一行的次级“切换介绍角度”；保留品牌、语言和登录。把主CTA移到标题、积分条和一句简介之后、时间卡之前，C文字改为“选玩法，开始选号”，继续指向现有 `#play`。A可用“选一个玩法开始”，B保留核验定位但让“选玩法，用积分选号”成为同处可见的清楚行动。这样无需新增页面，首次访客不用先读完整时间卡才能找到开始入口。
2. **合并同屏重复核验CTA，形成一个稳定的核验入口。** 位置是C手机时间卡底部与其下方CTA行；删除CTA行里重复的“查看本期规则与时间”，保留时间卡按钮并改为“本期规则、时间与核验”。B同处保留时间卡入口，原“看懂本期开奖依据”不再与之并排重复，可改为该卡上方的一句说明“先锁定规则，再核验行情”。桌面现有“开奖核验”导航继续保留。来源、停售、最早核验和“来源缺失或分歧就等待”仍随时间卡呈现，入口继续使用现有本期可读核验页。
3. **让奖池与结果区准确表达首期进程。** 位置是三主题共享奖池数字、下方“最近开奖结果”卡及其现有规则链接。数字改为“101,000分”，标题用“共享虚拟积分池”，原“全部玩法共用；无现金价值”紧贴数字保留；首期尚无结果时，将“最近开奖结果”及“本站已公布号码/历史……”替换为“本期进度｜尚未开奖”和“首期开放选号，尚无真实结果”。用现有卡内空间给出“11月2日16:30停售 → 11月4日05:00起核验 → 来源一致后公布（北京时间）”，保留缺失或分歧等待说明。现有链接统一为“查看本期规则与核验”，其旁用一句短说明交代“可复算公开输入；原始行情响应与完整账本不在认证范围”。这能把池的单位、当前等待原因与检查路径放在同一个任务上下文中，不制造结果或承诺准时开奖。
