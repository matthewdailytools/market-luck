# 公开奖：一分钟独立复算演示

2026-11-01，北京时间。先保存本分镜，再制作图像与视频。语言沿用项目中文、英文；不需要新增用户素材或等待分镜审批。

## 三种结构与选择

1. 完整安装路线：clone、依赖安装、配置和复算。网络等待会挤占一分钟，不选。
2. 号码揭晓路线：先展示号码，再展示玩法。容易混淆受控样本与自然开奖，不选。
3. **证据挑战**：读承诺 → 真实离线核验 → 改一个字符 → 拒绝 → 邀请独立审阅。选择此结构，一分钟内给出可执行动作和明确反例。

目标是让访问者愿意运行一条命令，自己检查一个含真实外部签名的受控样本。开头问“号码公开，还能自己重算吗”，结尾回答“下载证据，独立复算，提出质疑”。

## 制作方法与事实边界

采用 Lemo-Opuscar 的 Living Screencast 方法：高分辨率、按真实产品文字重绘的界面与终端；小像素引导员站在实际 DOM 边缘；光标代表用户。不是录像截图拼接，也不是一次自然行情开奖的录屏。命令输出与核验状态来自实际执行生成的 `demo-evidence.json`，视频始终标“受控回放 / Controlled replay”；片尾保留根权限、拒绝揭晓和隐藏候选风险。

产品本身的蓝、白和黄色为主色。学习 GitHub 开发者演示的可复制步骤和系统 Guided Tour 的平静节奏，不复制其 UI、人物、音乐或镜头。引导员为原创像素问号球，仅用于讲解，不表示项目新增了桌面宠物或自动助手功能。

1280×720、30 fps、60 秒。提供双语烧录字幕及独立中英文 SRT；无旁白，便于 GitHub 静音观看。原创程序合成声音包括低音量环境底、键盘点击、通过/拒绝提示和少量正弦/方波音符；无第三方音乐。音频目标 −14 LUFS，峰值低于 −1 dBTP。字体使用渲染环境的系统中文字体，不分发字体文件。

渲染在 GitHub 托管隔离 Linux Chromium 中运行，不访问个人浏览器、不连接真实账户或生产 API。源文件、字幕、证据与 PNG 入库，MP4/GIF 作为 Release 附件，并保留本地副本。使用项目已有 Playwright 和系统 ffmpeg，独立实现渲染器；不修改风格库。

## 镜头与节奏

| 时间 | 内容、景别与运动 | 目的、声音 |
|---|---|---|
| 0–6 秒 | 全景证据窗口，轻推入本期规则标题；问号球从标题边缘探出 | 三秒内出现“能自己重算吗”；短开场双音 |
| 6–12 秒 | 中景移动至 MD5/SHA-256 和独立日志签名时间，保持可读 | 解释先承诺、后揭晓；轻点声跨入下一章 |
| 12–18 秒 | 平移到终端，逐字显示实际 verifier 命令，Enter HUD | 明示依赖已安装，演示不含安装等待；键盘声，17.6 秒近静音 |
| 18–24 秒 | 推入核验清单，逐项显示实际通过项 | 真实外部签名；通过提示 |
| 24–32 秒 | 拉回完整终端与复算号码；停留阅读 | 11 项检查和所有玩法复算；稀疏音符 |
| 32–38 秒 | 分屏插入随机数修改，原/改字符高亮，运行临时副本 | 单字符反例；35.6 秒近静音，Enter 提示 |
| 38–46 秒 | 轻推失败状态，保留实际错误类型和退出码 | 被修改的秘密不能通过；低双音，不显示伪造中奖号码 |
| 46–52 秒 | 拉回三项边界说明 | 不把可检测误称为绝对无法作弊；环境音尾音跨章 |
| 52–60 秒 | 全景结束窗口、仓库地址、Clone → Reproduce → Review | 留足八秒读 CTA；结尾原创短动机 |

基础节奏 60 BPM，章节点均在整秒；光标点击和状态更新共用同一时间线。慢推、平移、分屏重构、拉回四类镜头，18 秒清单完成与 38 秒失败为主要声音节点。字幕最短六秒，避免压住主体；命令和结果在固定位置停留。
